Cribrum

A local photo sieve for Android.

Cribrum finds images on your phone that you can delete without losing memories that matter. It scans local storage, suggests candidates for your review, and keeps deletions in a 30-day trash.

Download latest APK Android 11+ · Free software (GPLv3)

What it does

  • Finds photos worth deleting. Cribrum scans storage for exact duplicates, similar copies, blurry shots, screenshots, bad exposures, and messaging clutter like WhatsApp stickers.
  • Suggests, never deletes on its own. The app surfaces candidates for your review. You decide what to keep and what to trash. Nothing is removed without your confirmation.
  • Runs on the phone. All scanning and analysis happen on the device. No photos, hashes, or metadata ever leave your phone. The app works offline and needs no account.
  • Keeps a 30-day trash. Deleted files move to an app-managed folder on storage instead of disappearing immediately. They remain there for 30 days before purge, so you can restore anything deleted by mistake.

Requirements

  • Android 11 or newer (API 30+). The app relies on storage rules and file management APIs introduced in Android 11.
  • All files access (MANAGE_EXTERNAL_STORAGE). Standard gallery apps only see files indexed by MediaStore, missing hidden folders such as WhatsApp sent and received media. Cribrum uses all files access to run a deep scan and find clutter across the entire shared storage.
  • Sideloaded distribution. Google Play restricts all files access to a narrow set of app categories. Distributing Cribrum directly as a sideloaded APK allows full-storage cleanup without Play Store policy restrictions.

How to install

  1. Download the APK. Get the latest release from the GitHub releases page.
  2. Allow the install. Open the downloaded file. When Android asks for permission to install unknown apps from your browser or file manager, allow it and confirm.
  3. Check the SHA-256. Each release includes a .sha256 checksum file. You can verify the APK digest with sha256sum cribrum-*.apk before running it.
