A local photo sieve for Android

Cribrum scans storage for images you can safely delete, surfaces candidates for your review, and keeps deletions in a trash for 30 days by default.

Download latest APK View source on GitHub

Requires Android 11 or newer. Free software under GPL-3.0.

The images in the screenshots are drawn in code, and the counts are made up.

What it finds

Exact copies
Matches identical files byte-for-byte using xxHash, marking the best copy to keep.
Similar copies
Finds recompressed and resized copies with perceptual hashes and MobileCLIP embeddings, suggesting the highest-quality version to keep.
Bursts
Clusters photos taken in quick succession and suggests keeping the sharpest shot with open eyes.
Blurry
Measures sharpness with Laplacian variance on subject areas, preserving intentional portrait blur.
Too dark or too bright
Identifies underexposed pocket shots, black frames, and blown-out frames using luminance histograms.
Screenshots
Detects screen captures by path, screen-matching dimensions, and absent camera metadata.
Documents and notes
Detects slides, whiteboards, handwritten notes, receipts, and printed pages using text coverage and MobileCLIP classification.
Forwarded
Flags memes and greeting images in messaging folders lacking camera metadata using zero-shot classification.
WhatsApp stickers
Finds reaction stickers saved in WhatsApp sticker folders across storage.

Design principles

Practical over pretty
A clean, minimal UI whose features actually work.
Recall over precision
Surfacing an image that turns out to be worth keeping is fine. Missing clutter that could have been deleted is not.
Private by design
All scanning and analysis run on your device. No photos, hashes, or metadata ever leave your phone. Cribrum explicitly removes network permissions.
Nothing is lost by accident
Every deletion is confirmed and reversible for 30 days by default (7 to 90 days in settings). Files move to Cribrum's trash folder on shared storage and can be restored to their original paths.

Permissions and sideloading

Standard gallery applications use Android MediaStore, which only indexes public media folders. MediaStore ignores folders with .nomedia markers, such as WhatsApp Images/Sent, where silent storage waste accumulates.

Cribrum asks for MANAGE_EXTERNAL_STORAGE (All files access) to scan hidden directories directly and manage its trash folder on shared storage. Because Google Play restricts this permission to file managers, Cribrum is distributed as a direct APK download on GitHub.

Cribrum explicitly removes the android.permission.INTERNET permission in its manifest, stripping even telemetry from bundled libraries. The app cannot open network connections or send data anywhere.

Install

  1. 1

    Download the APK

    Get the latest release from the GitHub releases page. You can optionally verify package integrity with the SHA-256 digest:

    sha256sum -c cribrum-*.apk.sha256
  2. 2

    Allow unknown apps

    Open the downloaded package. When Android asks to allow installation from your browser or file manager, confirm to proceed.

  3. 3

    Grant storage access

    On first launch, grant All files access when Android prompts in system settings, so Cribrum can explore hidden folders across storage.

  4. 4

    Scan and review

    Tap Scan now to run the initial scan, or leave it to run automatically overnight while charging. Candidates will appear grouped by category for your review.
